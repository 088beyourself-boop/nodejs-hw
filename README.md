# nodejs-hw

Express and MongoDB server for the Node.js homework.

## Run locally

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env` if the environment file is missing.

## Endpoints

- `GET /notes`
- `GET /notes/:noteId`
- `POST /notes`
- `PATCH /notes/:noteId`
- `DELETE /notes/:noteId`
